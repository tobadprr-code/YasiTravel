Sistema de gestión y calculadora inteligente de viajes para servicio de remis.

---

## ✨ Características

- Calculadora inteligente de precios de viajes
- Registro de viajes realizados
- Gestión de choferes y vehículos
- Historial de clientes
- Reportes de ingresos
- Interfaz simple y rápida de usar

---

## 🛠️ Tecnologías

- PHP
- JavaScript
- MySQL
- HTML + CSS (con diseño responsive)
